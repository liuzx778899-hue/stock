# 需求文档：数据质量趋势分析

创建时间：2026-05-04
最后更新：2026-05-04
状态：待优化

## 背景

数据质量页面已支持日期区间选择 + 趋势折线图（第五十一轮），但存在两个问题：
1. "开始检查"按钮只检查当前数据，不支持对历史时间段批量生成报告
2. 3 个类别 × 4 条线 = 12 条线挤在 3 个图里，太乱

## 优化目标

1. 质量检查支持指定日期区间，批量生成报告
2. 图表从 3 个堆叠改为 1 个 + Tab 切换，清爽可读

## 功能需求

### 优化 1：质量检查支持日期区间

- [ ] `POST /api/quality/check` 增加 `start_date` + `end_date` 参数（可选，不传则检查当前）
- [ ] 传了日期区间，则对区间内每一天生成一份质量报告
- [ ] 按钮文字改为"检查区间段"

### 优化 2：图表简化

- [ ] 3 个面板合并为 1 个，顶部加 Tab 切换类别
- [ ] 去掉"总分"线（= 三个维度的平均值，不需要单独一条线）
- [ ] 只保留 3 条线：完整度（绿）、新鲜度（黄）、异常检测（红）
- [ ] 图表下方显示当前选中日期的三个维度数值

## 不做的事

- 不做自动定时批量检查
- 不做导出报告

## 验收标准

- [ ] 选择日期区间点击"开始检查"→ 区间内每一天生成报告
- [ ] 单图 + 3 个 Tab 切换类别，显示清晰
- [ ] 3 条线颜色区分明确（绿/黄/红），图例可点击切换
- [ ] 无数据的天不连线
