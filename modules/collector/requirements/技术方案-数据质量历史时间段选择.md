# 技术方案：数据质量历史时间段选择

创建时间：2026-05-03
状态：待开发

## 1. 技术选型

前端日期选择器使用原生 HTML `<input type="date">`，无需引入第三方组件。后端在现有 `get_latest_report()` 基础上增加 `date` 参数过滤。

## 2. 系统架构

```
前端日期选择器 → onChange → fetch(/api/quality/report?date=YYYY-MM-DD)
                                    ↓
                            QualityService.get_latest_report(date=xxx)
                                    ↓
                            query.filter(cast(check_time, DATE) == target_date)
                                    ↓
                            返回评分卡片数据 + 异常详情
```

## 3. 接口变更

### 3.1 GET /api/quality/report 增加 date 参数

```
原: GET /api/quality/report?category=stock_basic
新: GET /api/quality/report?category=stock_basic&date=2026-05-02
```

- `date` 可选，格式 YYYY-MM-DD
- 不传则返回最新报告（保持向后兼容）

`get_latest_report()` 增加 `target_date: Optional[str] = None` 参数：

```python
def get_latest_report(self, category=None, target_date=None):
    for cat in self.CATEGORIES:
        query = self.session.query(DataQualityReport) \
            .filter(DataQualityReport.data_category == cat)
        
        if target_date:
            from sqlalchemy import cast, DATE
            query = query.filter(
                cast(DataQualityReport.check_time, DATE) == target_date
            )
```
