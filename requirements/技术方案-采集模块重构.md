## 设计目标

将采集模块从「面向数据源的代码」重构为「面向数据类别的架构」。核心思路：**业务层只关心"我需要什么数据"，不关心"数据从哪个源来"**。

## 技术选型

- 设计模式：Strategy（策略）+ Adapter（适配器）+ Chain of Responsibility（责任链）+ Template Method（模板方法）
- 抽象方式：ABC 抽象基类定义接口契约
- 领域模型：Python dataclass（与数据源无关的纯数据结构）
- 注册发现：显式注册（非自动扫描，可控且明确）

## 核心抽象设计

### DataProvider 接口（`adapters/base.py`）

```python
from abc import ABC, abstractmethod
from dataclasses import dataclass, field
from typing import List, Optional
from enum import Enum
import pandas as pd

class DataCategory(Enum):
    STOCK_BASIC = "stock_basic"
    STOCK_INDUSTRY = "stock_industry"
    STOCK_AREA = "stock_area"
    KLINE_DAILY = "kline_daily"
    REALTIME_QUOTE = "realtime_quote"

@dataclass
class ProviderCapability:
    """数据源能力声明"""
    category: DataCategory
    fields: List[str]
    quality_score: float = 0.5   # 0-1，越高越好
    cost_type: str = "free"

class DataProvider(ABC):
    """数据源提供者抽象基类

    每个数据源实现此基类，按需重写 fetch_* 方法。
    不要求实现所有方法——只实现数据源实际支持的数据类别。
    """

    @property
    @abstractmethod
    def provider_name(self) -> str: ...

    @property
    @abstractmethod
    def capabilities(self) -> List[ProviderCapability]: ...

    # 子类按需重写以下方法
    def fetch_stock_basic(self) -> pd.DataFrame:
        raise NotImplementedError

    def fetch_industry_mapping(self) -> dict:  # {code: industry_name}
        raise NotImplementedError

    def fetch_area_mapping(self) -> dict:  # {code: area_name}
        raise NotImplementedError

    def fetch_kline(self, symbol: str, start: str, end: str, adjust: str = "qfq") -> pd.DataFrame:
        raise NotImplementedError

    def fetch_realtime(self) -> pd.DataFrame:
        raise NotImplementedError
```

```python
class EastmoneyProvider(DataProvider):

        ProviderCapability(DataCategory.STOCK_INDUSTRY,

    ]

    def fetch_stock_basic(self) -> pd.DataFrame:
        return ak.stock_zh_a_spot_em()

    def fetch_kline(self, symbol, start, end, adjust="qfq"):

        return ak.stock_zh_a_spot_em()
```

**关键点**：`capabilities` 声明了这个数据源能提供什么 + 每个字段是什么 + 质量评分。编排器依赖此信息做调度决策。

### DataSourceRegistry（`adapters/registry.py`）

```python
class DataSourceRegistry:
    """数据源注册中心"""

    def __init__(self):
        self._providers: List[DataProvider] = []

    def register(self, provider: DataProvider):
        self._providers.append(provider)
        # 按质量评分排序
        self._providers.sort(key=lambda p: max(
            c.quality_score for c in p.capabilities), reverse=True)

    def get_providers_for(self, category: DataCategory) -> List[DataProvider]:
        """获取能提供指定数据类别的 provider 列表（按质量排序）"""
        return [p for p in self._providers
                if any(c.category == category for c in p.capabilities)]

    def get_all_providers(self) -> List[DataProvider]:
        return self._providers

    def get_provider(self, name: str) -> Optional[DataProvider]:
        for p in self._providers:
            if p.provider_name == name:
                return p
        return None

# 全局实例
registry = DataSourceRegistry()
```

### DataOrchestrator（`services/data_orchestrator.py`）

```python
class DataOrchestrator:
    """数据编排器：调度多数据源，自动补齐缺失字段"""

    def __init__(self, registry: DataSourceRegistry):
        self.registry = registry
        self.validator = DataValidator()

    def collect_stock_basic(self, progress_callback=None) -> pd.DataFrame:
        """采集股票基础信息（含行业/地域补齐）"""
        providers = self.registry.get_providers_for(DataCategory.STOCK_BASIC)

        # Step 1: 主数据源获取基础列表
        df = None
        last_error = None
        for p in providers:
            try:
                df = p.fetch_stock_basic()
                if df is not None and not df.empty:
                    break
            except Exception as e:
                last_error = e
                continue

        if df is None:
            raise last_error or Exception("所有数据源都无法获取股票基础信息")

        # Step 2: 检查并补齐行业字段
        if 'industry' not in df.columns or df['industry'].isna().all():
            industry_providers = self.registry.get_providers_for(DataCategory.STOCK_INDUSTRY)
            for p in industry_providers:
                try:
                    mapping = p.fetch_industry_mapping()
                    if mapping:
                        df['industry'] = df['symbol'].map(mapping)
                        break
                except Exception:
                    continue

        # Step 3: 检查并补齐地域字段
        if 'area' not in df.columns or df['area'].isna().all():
            area_providers = self.registry.get_providers_for(DataCategory.STOCK_AREA)
            for p in area_providers:
                try:
                    mapping = p.fetch_area_mapping()
                    if mapping:
                        df['area'] = df['symbol'].map(mapping)
                        break
                except Exception:
                    continue

        return df

    def collect_kline(self, symbol: str, start: str, end: str) -> pd.DataFrame:
        """采集K线数据（自动降级）"""
        providers = self.registry.get_providers_for(DataCategory.KLINE_DAILY)
        for p in providers:
            try:
                df = p.fetch_kline(symbol, start, end)
                if df is not None and not df.empty:
                    # 验证关键字段
                    missing = self.validator.check_fields(df, ["open","high","low","close"])
                    if not missing:
                        return df
                    # 有关键字段缺失，尝试下一个数据源
            except Exception:
                continue
        return pd.DataFrame()
```

## 风险点

| 风险 | 影响 | 缓解措施 |
|------|------|----------|
| 重构期间功能不可用 | 用户无法采集数据 | 分支开发，保留旧代码到合并前 |
| 新架构引入性能回退 | 多数据源补齐增加采集耗时 | 并行请求多个数据源，同一源的补齐不额外请求 |
| 能力声明与实际不符 | 编排器信任了错误的能力声明 | Validator 采集后校验，发现偏差自动降低 quality_score |
| 向后兼容性 | main.py / web_app.py 导入路径变化 | 保留旧模块的 import 别名（deprecation warning） |
