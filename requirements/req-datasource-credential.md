# 需求文档：数据源凭证 Web 配置页面
创建时间：2026-05-08
状态：待开发

## 背景

#159 新增了 Tushare Pro（付费，需 token）和 JoinQuant（免费，需账号密码）两个数据源。当前只能通过环境变量 `.env` 配置凭证，无 Web 界面维护入口。付费数据源购买后也找不到地方填凭证。

## 目标

1. 数据源管理页面，点击需要凭证的数据源 → 弹出配置窗口
2. 窗口展示该数据源所需凭证字段（token / username+password / 其他）
3. 保存后凭证加密存入 `system_config` 表
4. 已保存的凭证回显为 `****`

## 涉及文件

- `web_app.py` — API 端点：读取/保存数据源凭证
- `modules/collector/web/templates/index.html` — 前端弹窗表单
- `common/db_config_store.py` — 复用已有加密存储逻辑（`system_config` 表）

## 窗口内容

```
┌── 配置 Tushare Pro ──────────────────┐
│                                       │
│  Token:  [________________]           │
│                                       │
│  提示: 注册获取 token → tushare.pro   │
│                                       │
│  [测试连接]              [保存] [取消] │
└───────────────────────────────────────┘
```

- 每个数据源窗口展示其所需字段（由后端 API 返回字段定义）
- 密码/token 类字段回显 `****`
- "测试连接" 按钮可选（非必须）

## 验收标准

- [ ] 数据源管理列表，收费数据源可点击打开配置弹窗
- [ ] 弹窗展示该数据源所需凭证字段
- [ ] 保存后凭证加密存入 `system_config` 表
- [ ] 已有凭证回显 `****`
- [ ] 配置后数据源能使用保存的凭证

## 不做的事

- 不修改 `system_config` 表结构
- 不修改现有加密算法
- 不修改 Provider 适配器代码（tushare/jqdata 已正确读取环境变量）
