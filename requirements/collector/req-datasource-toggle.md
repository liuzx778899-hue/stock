# 需求文档：数据源启用/禁用开关

创建时间：2026-05-03
状态：待开发

## 背景

用户未充值必盈 API，但没有开关控制是否使用。即使手动禁用了 Licence，自动模式下编排器仍会尝试调用必盈 API（失败后才降级），增加不必要的超时延迟。用户希望有一个开关来禁用不需要的数据源。

## 目标

在数据源管理页面增加启用/禁用开关，关闭后：
1. 自动模式不调用该数据源
2. 强制选择下拉框不显示该数据源
3. 页面上的 Provider 卡片显示禁用状态

## 功能需求

### 核心功能

- [ ] 功能1：后端新增 `POST /api/datasource/toggle/{name}` 接口，运行时切换 Provider enabled 状态
- [ ] 功能2：数据源管理页面每个内置 Provider 增加启用/禁用开关
- [ ] 功能3：禁用的 Provider 在强制选择下拉框中不显示
- [ ] 功能4：禁用的 Provider 在自动模式采集时不调用

## 不做的事

- 不禁用 eastmoney/sina/tencent（保留至少一个可用 HTTP 源）
- 不持久化到文件（重启恢复 providers.yaml 默认值，可接受）

## 验收标准

- [ ] 点击必盈的"禁用"按钮后，Provider 卡片变灰
- [ ] 强制选择下拉框中不再出现必盈
- [ ] 自动模式采集不再尝试调用必盈 API
- [ ] 点击"启用"按钮恢复
