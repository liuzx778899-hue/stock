# 需求文档：数据质量历史时间段选择

创建时间：2026-05-03
状态：待开发

## 背景

当前数据质量页面只显示最新一次检查结果。用户需要查看历史某一天的质量报告，以便对比不同时间点的数据质量变化趋势。

## 目标

在数据质量页面增加日期选择器，用户可以切换查看不同日期的质量报告。默认展示当天。

## 用户故事

- 作为一个数据管理员，我希望选择昨天的日期，查看昨天的数据质量评分，以便对比今日和昨日的数据质量变化
- 作为一个用户，我打开质量页面时默认看到今天的报告，不需要额外操作

## 功能需求

### 核心功能

- [ ] 功能1：质量页面顶部增加日期选择器，默认选中当天
- [ ] 功能2：切换日期后，自动加载该日期的质量报告（评分卡片 + 异常详情）
- [ ] 功能3：后端 `/api/quality/report` 支持 `date` 参数，查询指定日期的报告

### 扩展功能（有时间再做）

- [ ] 时间段趋势图：展示近 N 天质量评分趋势折线图

## 不做的事

- 不做实时刷新（切换日期后手动触发加载即可）
- 不做时间段范围查询（一次只查一天）
- 不做自定义时间范围选择器（只用日期，不用日期时间）

## 非功能需求

- 日期切换后接口响应 < 1 秒
- 兼容 Chrome、Edge 浏览器

## 验收标准

- [ ] 质量页面顶部有日期选择器，默认值为当天（格式：YYYY-MM-DD）
- [ ] 选择历史日期，评分卡片更新为该日期的数据
- [ ] 选择的历史日期无报告时，显示"该日期暂无质量报告"
- [ ] API `GET /api/quality/report?date=2026-05-02` 返回该日期的报告数据
