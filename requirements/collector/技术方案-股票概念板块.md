## 2. 数据库设计

### 2.1 新增表

```sql
-- 概念板块表
CREATE TABLE concept (
    id INT AUTO_INCREMENT PRIMARY KEY,
    name VARCHAR(100) NOT NULL UNIQUE COMMENT '概念名称',
    block_type INT COMMENT '通达信板块类型',
    stock_count INT DEFAULT 0 COMMENT '所含股票数',
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    updated_at DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP
) COMMENT='概念板块';

-- 股票-概念关联表（多对多）
CREATE TABLE stock_concept (
    id INT AUTO_INCREMENT PRIMARY KEY,
    symbol VARCHAR(20) NOT NULL COMMENT '股票代码',
    concept_id INT NOT NULL,
    UNIQUE KEY uk_stock_concept (symbol, concept_id),
    INDEX idx_symbol (symbol),
    INDEX idx_concept_id (concept_id)
) COMMENT='股票-概念关联';
```

### 2.2 ORM 模型

```python
# models.py 新增
class Concept(Base):
    __tablename__ = 'concept'
    id = Column(Integer, primary_key=True, autoincrement=True)
    name = Column(String(100), nullable=False, unique=True)
    block_type = Column(Integer)
    stock_count = Column(Integer, default=0)
    created_at = Column(DateTime, default=datetime.now)
    updated_at = Column(DateTime, default=datetime.now, onupdate=datetime.now)

class StockConcept(Base):
    __tablename__ = 'stock_concept'
    id = Column(Integer, primary_key=True, autoincrement=True)
    symbol = Column(String(20), nullable=False)
    concept_id = Column(Integer, nullable=False)
    __table_args__ = (
        UniqueConstraint('symbol', 'concept_id', name='uk_stock_concept'),
        Index('idx_symbol', 'symbol'),
        Index('idx_concept_id', 'concept_id'),
    )
```

### 2.3 为什么不用 stock_basic 加字段

| 方案 | 存储 | 查询"锂电池概念股" | 更新单只股票概念 | 扩展性 |
|------|------|-------------------|-----------------|--------|
| 逗号分隔字段 | `concepts = "锂电,新能车"` | `WHERE concepts LIKE '%锂电%'` — 全表扫描 | 字符串拼接，易冲突 | 差 |
| JSON 字段 | `concepts = ["锂电","新能车"]` | MySQL JSON_CONTAINS — 仍需全表 | 序列化/反序列化 | 中 |
| **多对多表** | 2 张表 | `JOIN stock_concept WHERE concept_id=5` — 走索引 | INSERT/DELETE 一行 | **好** ✅ |

## 3. 数据采集

### 3.1 采集流程

```
采集触发（基础信息采集完成后 or 手动触发）
  │
  ├─ 1. 下载 block_gn.dat（mootdx TCP, ~1.5MB, ~10秒）
  ├─ 2. BlockReader 解析 → [{blockname, block_type, code_list}, ...]
  ├─ 3. 过滤空名称 + type 0 占位块
  ├─ 4. 批量 UPSERT concept 表（concept name + stock_count）
  ├─ 5. DELETE stock_concept 全表旧数据
  ├─ 6. 批量 INSERT stock_concept 新数据（138 万条）
  └─ 7. 更新采集日志
```

### 3.2 TdxProvider 新增方法

```python
# adapters/mootdx_provider.py 新增
def fetch_concept_mapping(self) -> Dict[str, List[str]]:
    """获取概念板块映射
    Returns:
        {concept_name: [symbol1, symbol2, ...]}
    """
    from tdxpy.reader.block_reader import BlockReader, BlockReader_TYPE_GROUP
    
    # 下载 block_gn.dat
    quotes = self._quotes
    meta = quotes.client.get_block_info_meta('block_gn.dat')
    # ... 分块下载逻辑 ...
    
    grouped = BlockReader.get_data(file_content, BlockReader_TYPE_GROUP)
    
    result = {}
    for g in grouped:
        name = g['blockname'].strip()
        if not name or name.startswith('\x00'):
            continue
        codes = [c.strip() for c in g['code_list'].split(',') if c.strip()]
        if codes:
            result[name] = codes
    
    return result
```

## 6. 性能评估

| 操作 | 耗时 | 说明 |
|------|------|------|
| 下载 block_gn.dat | ~10 秒 | TCP 下载 1.5MB |
