# 需求文档：个股K线分析

创建时间：2026-05-03
状态：待开发

## 背景

用户需要像通达信/同花顺一样查看个股 K 线图，支持切换日线/周线/月线/年线，进行技术分析。当前系统有 K 线数据但缺少可视化展示。

## 目标

新增个股详情页面，展示交互式 K 线图（蜡烛图 + 成交量 + 均线），用户可切换周期、拖拽缩放查看历史走势。

## 用户故事

- 作为一个投资者，我点击某只股票后看到 K 线图，以便分析走势
- 作为一个用户，我切换周线查看中长期趋势
- 作为一个用户，我看到 MA5/MA10/MA20/MA60 均线帮助判断买卖点

## 功能需求

### 核心功能

- [ ] 功能1：个股详情页 — K 线蜡烛图（红涨绿跌）+ 成交量柱 + 均线叠加
- [ ] 功能2：均线 — MA5（白）、MA10（黄）、MA20（紫）、MA60（绿）四条均线
- [ ] 功能3：周期切换 — 日K / 周K / 月K / 年K Tab 切换
- [ ] 功能4：股票列表点击股票代码/名称 → 跳转个股K线详情页
- [ ] 功能5：后端 API 支持多周期 K 线数据查询（周月年从日线 pandas resample 聚合）
- [ ] 功能6：缩放拖拽 — 鼠标滚轮缩放 + 拖拽平移 + 底部滑块选择时间范围
- [ ] 功能7：十字光标 & 数据看板 — 悬停显示当日 OHLCV + 涨跌幅

### 扩展功能

- [ ] MACD / KDJ / RSI 常用技术指标切换
- [ ] 前后复权切换

## 不做的事

- 不做实时行情推送（个股页不自动刷新）
- 不做分时图（分钟级数据量太大）
- 不做画线工具
- 不做自选股收藏

## 非功能需求

- K 线图首次加载 < 2 秒
- 周期切换 < 0.5 秒
- 支持 Chrome、Edge 浏览器
- 日线数据量：单只股票至少 800 根 K 线

## 验收标准

- [ ] 日K/周K/月K/年K Tab 可切换
- [ ] 蜡烛图红涨绿跌 + MA5(白)/MA10(黄)/MA20(紫)/MA60(绿) 均线
- [ ] 成交量柱状图（红涨绿跌与 K 线同色）
- [ ] 鼠标滚轮缩放 + 拖拽平移 + 底部时间范围滑块
- [ ] 十字光标悬停显示 OHLCV + 涨跌幅
- [ ] 股票列表点击代码 → 进入个股详情
