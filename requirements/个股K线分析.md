# 需求文档：个股K线分析

创建时间：2026-05-03
最后更新：2026-05-04
参照效果图：`requirements/K线图/微信图片_202605040203*.jpg`（同花顺手机版截图，1206x2622）

## 背景

用户提供同花顺手机版截图作为参照标准，需要达到相同视觉效果和操作体验。

## 目标

用 KLineChart 替换当前 ECharts 实现，达到同花顺手机版的视觉效果和交互体验。

## 参照效果图要求（逐项对标）

### 顶部信息栏
- 左上角：← 返回按钮
- 中部：股票名称 + 代码，如"平安银行 000001"
- 右上角：当前价格（大字）+ 涨跌额 + 涨跌幅（红涨绿跌）

### 主图区域（~45% 高度）
- K 线蜡烛图：红涨绿跌，放量实心、缩量空心
- MA5(白) / MA10(黄) / MA20(紫) / MA60(绿) 四条均线叠加
- BOLL 布林带（可选）：中轨实线 + 上/下轨虚线
- 右侧价格坐标轴
- 底部日期坐标轴
- 横向虚线网格
- 十字光标：竖线贯穿所有面板，横线在主图内

### 副图1：成交量 VOL（~12% 高度）
- 红涨绿跌柱状图，颜色与主图K线一致
- MA5/MA10 均量线可选叠加

### 副图2：MACD（~12% 高度）
- DIF 快线（白）+ DEA 慢线（黄）
- 红绿柱（正红负绿）
- 零轴参考线

### 副图3：RSI（~12% 高度）
- RSI6(白) + RSI12(黄) + RSI24(紫) 三线
- 30 超卖线（绿虚线）+ 70 超买线（红虚线）

### 底部工具栏
- 指标选择按钮（可切换副图指标：MACD/RSI/KDJ/VOL等）
- 周期切换：日K / 周K / 月K / 年K
- 复权切换：前复权 / 后复权 / 不复权

### 交互要求
- 单指拖拽左右平移
- 双指/滚轮缩放（横向放大缩小K线数量）
- 十字光标跟随手指/鼠标移动，所有面板同步
- 长按/悬停显示当日详细数据浮窗（开/高/低/收/量/额/涨幅）
- 缩放时自动加载更多历史数据

## 功能需求

### 核心功能

- [ ] 功能1：KLineChart 深色主题，与同花顺色调一致
- [ ] 功能2：蜡烛图空心/实心按涨跌+量能组合判定
- [ ] 功能3：四面板（主图 + VOL + MACD + RSI），比例 45/12/12/12
- [ ] 功能4：MA5/MA10/MA20/MA60 + BOLL 叠加主图
- [ ] 功能5：周期切换（日K/周K/月K/年K）
- [ ] 功能6：十字光标全面板联动
- [ ] 功能7：顶部价格信息栏（当前价/涨跌额/涨跌幅）
- [ ] 功能8：缩放拖拽流畅（>30fps）
- [ ] 功能9：股票列表点击 → 个股详情页

### 扩展功能

- [ ] 指标切换面板（MACD/RSI/KDJ 可替换副图位）
- [ ] 前后复权切换
- [ ] 画线工具（线段/射线/平行线）

## 不做的事

- 不做分时图（需要分钟级数据，数据量太大）
- 不做实时行情推送
- 不做自选股

## 验收标准

- [ ] 深色背景，视觉与同花顺截图一致
- [ ] 蜡烛红涨绿跌，放量实心/缩量空心
- [ ] 四面板比例正确，十字光标全面板联动
- [ ] 周期切换后数据正确加载
- [ ] 缩放拖拽流畅无卡顿
- [ ] 顶部价格栏实时显示正确
- [ ] 股票列表点击进入个股详情
