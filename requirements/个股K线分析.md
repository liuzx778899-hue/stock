# 需求文档：个股K线分析

创建时间：2026-05-03
最后更新：2026-05-04
状态：待开发

## 背景

用户需要像同花顺一样查看个股 K 线图，支持日/周/月/年线切换，叠加常用技术指标进行专业分析。

## 目标

新增个股详情页面，参照同花顺布局：K线（含布林带+均线）+ 成交量 + MACD + RSI，支持周期切换和拖拽缩放。

## 页面布局（参照同花顺）

```
┌──────────────────────────────────────────┐
│ ← 返回    平安银行 000001    [日K][周K][月K][年K] │
├──────────────────────────────────────────┤
│                                          │
│   主图：K线蜡烛图 + BOLL(中/上/下轨)       │
│         + MA5(白) MA10(黄) MA20(紫) MA60(绿) │
│                                          │
├──────────────────────────────────────────┤
│   副图1：成交量 VOL（红涨绿跌柱）           │
├──────────────────────────────────────────┤
│   副图2：MACD（DIF快线/DEA慢线/红绿柱）     │
├──────────────────────────────────────────┤
│   副图3：RSI（RSI6/RSI12/RSI24 三线）      │
└──────────────────────────────────────────┘
```

## 功能需求

### 核心功能

- [ ] 功能1：K线蜡烛图（红涨绿跌）+ BOLL 布林带（中轨/上轨/下轨）
- [ ] 功能2：均线 — MA5(白)、MA10(黄)、MA20(紫)、MA60(绿) 四条均线
- [ ] 功能3：成交量 VOL — 红涨绿跌柱状图，与K线同色
- [ ] 功能4：MACD — DIF快线(白) + DEA慢线(黄) + 红绿柱
- [ ] 功能5：RSI — RSI6(白) + RSI12(黄) + RSI24(紫)，含 30/70 超卖超买参考线
- [ ] 功能6：周期切换 — 日K / 周K / 月K / 年K Tab
- [ ] 功能7：股票列表点击 → 个股详情页
- [ ] 功能8：滚轮缩放 + 拖拽平移 + 底部时间范围滑块
- [ ] 功能9：十字光标悬停显示各个副图的指标值

### 扩展功能

- [ ] 前后复权切换
- [ ] KDJ 指标副图
- [ ] 指标参数可调（如修改 BOLL 周期、RSI 天数）

## 不做的事

- 不做实时行情推送（个股页不自动刷新）
- 不做分时图
- 不做画线工具
- 不做自选股收藏

## 验收标准

- [ ] K线 + BOLL(3线) + MA(4线) 正确叠加
- [ ] 成交量柱红涨绿跌与 K 线颜色一致
- [ ] MACD 含 DIF/DEA 线 + 红绿柱
- [ ] RSI 含 3 条线 + 30/70 参考线
- [ ] 日K/周K/月K/年K 全部可切换
- [ ] 鼠标滚轮缩放 + 拖拽平移可用
- [ ] 十字光标在所有副图中同步显示
- [ ] 股票列表点击代码 → 进入详情页
