# 需求文档：概念板块 Hover Tooltip

创建时间：2026-05-05
状态：开发完成

## 背景

股票列表页的概念板块列当前最多显示 4 个概念标签，超出部分显示 `+N`。
用户无法快速查看一只股票的全部概念板块，需要点进详情页才能看到完整列表。

## 目标

鼠标悬停任意概念标签时，弹出 tooltip 显示该股票的全部概念板块名称。

## 验收标准

- [ ] 模板前端（templates/index.html）：Hover 概念标签显示 tooltip，列出全部概念
- [ ] Vue 前端（frontend/）：Hover 概念标签显示 tooltip，列出全部概念
- [ ] `+N` 标签 hover 也显示全部概念（不只是剩余部分）
- [ ] 无概念时 `-` 不显示 tooltip

## 不做的事

- 不新增概念详情页
- 不修改后端 API
- 不改变概念标签的显示数量（仍最多 4 个）
